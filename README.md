# MediaSelector

MediaSelector — настольное приложение для Windows 10/11 на Python и PySide6 для быстрого просмотра больших папок с фотографиями и видео и безопасного копирования выбранных файлов в другую папку, на внешний диск или флешку.

## Структура проекта

## Архитектура

- `main.py` запускает `QApplication` и главное окно.
- `app/main_window.py` содержит русскоязычный интерфейс, горячие клавиши, сохранение сеанса и связь между просмотрщиком, сканером и очередью копирования.
- `app/media_viewer.py` показывает изображения с сохранением пропорций, поддерживает поворот, масштабирование, перетаскивание, а также видео через QtMultimedia.
- `app/file_scanner.py` собирает список поддерживаемых фото и видео из одной или нескольких папок, включая вложенные папки.
- `app/copy_worker.py` копирует файлы блоками в фоновом потоке, проверяет размер и при включённой настройке SHA-256.
- `app/copy_manager.py` управляет `QThread` и передаёт изменения в интерфейс только через сигналы.
- `app/session_manager.py` и `app/settings_manager.py` сохраняют JSON-состояние в пользовательской папке приложения.
- `logs/copy_log.csv` создаётся автоматически и хранит журнал копирования.

## Установка Python

1. Откройте <https://www.python.org/downloads/windows/>.
2. Скачайте Python 3.11 или новее.
3. При установке обязательно включите пункт **Add python.exe to PATH**.
4. Проверьте установку в PowerShell:

```bash
python --version
```

## Создание виртуального окружения

В папке проекта выполните:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

1. В блоке **Куда копировать** выберите папку назначения.
2. В блоке **Где находятся фотографии и видео** добавьте одну или несколько исходных папок.
3. Выберите режим вложенных папок и сортировку.
4. Нажмите **Начать просмотр**.
5. Листайте файлы и нажимайте **Enter**, чтобы добавить текущий файл в очередь копирования.
6. Копирование идёт в фоне, просмотр можно продолжать.

Оригинальные файлы не удаляются и не перемещаются. Приложение выполняет только копирование.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| → | Следующий файл |
| ← | Предыдущий файл |
| Enter | Добавить текущий файл в очередь без дублей |
| Delete | Убрать отметку выбора у текущего файла, не удаляя его с диска |
| Space | Пауза/продолжение видео |
| Home | Первый файл |
| End | Последний файл |
| Ctrl+O | Выбрать папку-источник |
| Ctrl+S | Выбрать папку назначения |
| N | Следующий ещё не просмотренный файл |
| F11 | Полноэкранный режим |
| Escape | Выйти из полноэкранного режима |

## Совпадение имён

В интерфейсе есть настройка поведения, если в папке назначения уже существует файл с таким именем:

- **Добавить номер к имени** — значение по умолчанию: `photo.jpg`, `photo (1).jpg`, `photo (2).jpg`.
- **Пропустить файл**.
- **Спросить пользователя** — режим зарезервирован в настройках; для безопасной фоновой очереди рекомендуется использовать добавление номера.
- **Перезаписать**.

## Проверка результата

После копирования приложение проверяет, что файл существует и его размер совпадает с оригиналом. Дополнительно можно включить **Проверять контрольную сумму после копирования** — тогда будет сравниваться SHA-256, но для больших видео это может занять заметное время.

## Восстановление предыдущего сеанса

Сеанс автоматически сохраняется в пользовательской папке приложения, например `%APPDATA%\MediaSelector\session.json`. При следующем запуске приложение предложит продолжить предыдущий сеанс или начать новый. Восстанавливаются исходные папки, папка назначения, текущая позиция, просмотренные, выбранные и успешно скопированные файлы, сортировка и режим вложенных папок.

## Видео и кодеки Windows

Видеоплеер использует QtMultimedia и системные мультимедийные возможности Windows. MP4/M4V обычно работают сразу. MOV, AVI, MKV, WMV, WEBM и VOB могут зависеть от кодеков и компонентов, установленных в Windows.

## Сборка EXE через PyInstaller

Базовая команда:

```bash
pyinstaller --noconfirm --windowed --name MediaSelector main.py
```

Рекомендуемый вариант с подготовленным spec-файлом:

```bash
pyinstaller --noconfirm MediaSelector.spec
```

Готовая сборка появится в папке `dist\MediaSelector`.
